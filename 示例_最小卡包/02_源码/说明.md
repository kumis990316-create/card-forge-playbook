# 02_源码 · 放这里的东西

- `底图.png`：出成品用的立绘底图（512×768 以上，越清晰越好）。**文件名固定**，`build_card.js` 按这个名字找。
  （本目录里已有一张示例底图，正式做卡时换成你自己画的。）
- 没有底图时先跑一次占位图，检查整个流程能不能走通：

```bash
node 工具/build_card.js 示例_最小卡包 --placeholder
```

出图脚本会把角色卡本体写进 PNG 的文本块里（`tEXt` 关键字 `chara`）：**前台上传读的就是它**；后台导入要的 JSON，用 `export_json.js` 从这张 PNG 里解出来（内容与 `chara` 段逐字节一致，别拿 `01_卡片/` 的源件去交）。

> 卡内容只写在 `01_卡片/` 的两个 JSON 里；这里是底图与生成脚本，**不要把设定写在这儿**。
