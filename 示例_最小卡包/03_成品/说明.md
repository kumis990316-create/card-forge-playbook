# 03_成品 · 这里放生成的成品

`build_card.js` 把 `01_卡片/` 的两个 JSON 打包成一张 PNG；`export_json.js` 再从这张 PNG 里解出「导入用 JSON」。两个形态都写在这里（文件名＝卡名）。

```bash
node 工具/build_card.js  <卡包目录>                  # 用 02_源码/底图.png，出 <卡名>.png
node 工具/build_card.js  <卡包目录> --placeholder    # 没底图时先出占位图，只为走通流程
node 工具/export_json.js <卡包目录>                  # 从 PNG 解出 <卡名>_导入用.json
```

**三条规矩**：

- **不要手改这里的文件**。它们是生成物，下次重跑就覆盖掉。要改内容回 `01_卡片/`。
- **版本号别覆盖**。新版出 `米拉_v0.2.png`，旧版移进 `_历史/`；`character_version` 与文件名保持一致。
- **别拿 `01_卡片/` 的源件当导入件**：源件的 `character_book` 是空壳，导入进去是一张有开场、没规则的空卡。

两个形态各走哪条路：PNG 给**前台上传**（角色卡本体藏在它的文本块里），JSON 给**后台导入**（内容与 PNG 里那段逐字节一致）。详见 `05_输出端与平台.md` 三与 `03_检查器.md` 出成品。

（目录里现在这两份 `米拉.png` / `米拉_导入用.json` 是示例成品：底图是示例图，卡片本体就是 `01_卡片/` 那两个 JSON。）
