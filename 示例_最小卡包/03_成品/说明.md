# 03_成品 · 这里放生成的成品

`build_card.js` 把 `01_卡片/` 的两个 JSON 打包成一张 PNG，就写在这里（文件名＝卡名）。

```bash
node 工具/build_card.js <卡包目录>                  # 用 02_源码/底图.png
node 工具/build_card.js <卡包目录> --placeholder    # 没底图时先出占位图，只为走通流程
```

**两条规矩**：

- **不要手改这里的文件**。它是生成物，下次出图就把你的手改覆盖掉。要改内容回 `01_卡片/`。
- **版本号别覆盖**。新版出 `米拉_v0.2.png`，旧版移进 `_历史/`；`character_version` 与文件名保持一致。

导入 SillyTavern 用这张 PNG（角色卡本体藏在它的文本块里）；世界书另外导入 `01_卡片/` 里的世界书 JSON。
